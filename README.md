# 박프로 (Nimbalyst 한국어판 재구현)

Claude Code 에이전트와 함께 쓰는 **한국어 마크다운 작업공간**입니다.
`/Applications/Nimbalyst.app`(v0.81.7)을 REA로 분석해 핵심 기능을 파악한 뒤, 원본 코드를 복사하지 않고 처음부터 새로 구현했습니다.
UI·메뉴·대화상자·에이전트 응답이 모두 한국어로 동작합니다.

## 실행

```bash
npm install          # node-pty 권한 설정까지 자동으로 처리
npm run dev          # 개발 모드 (핫 리로드)
npm run build && npm start   # 빌드 후 실행
npm run dist         # macOS .app 만들기 (dist/ 폴더)
```

AI 기능은 로컬에 설치된 Claude Code(`claude`)를 사용합니다. 터미널에서 `claude` 로 한 번 로그인해 두거나 `ANTHROPIC_API_KEY` 를 설정하세요.
실행 파일 위치가 다르면 **설정 → Claude Code 실행 파일 경로**에 지정합니다.

## 구조

```javascript
src/main/       Electron 메인 프로세스 (파일, 감시, 이력, 트래커, 터미널, 에이전트, 한국어 메뉴)
src/preload/    렌더러에 노출하는 window.api
src/renderer/   React UI
  src/i18n/ko.ts   화면 문구 전부 (다른 언어는 같은 모양의 객체를 추가)
  src/modes/       파일 / 에이전트 / 트래커 모드
  src/components/  편집기, diff, 이력, 터미널, 채팅 등
```

## 원본과의 차이 (구현하지 않은 것)

원본은 팀 협업·클라우드 동기화·계정(Stytch)·GitHub PR·30여 개 확장(Excalidraw, CSV, PDF, 캔버스 등)·Codex/OpenCode 등 다른 에이전트·모바일 연동까지 포함합니다.
이 재구현은 로컬 단일 사용자용 핵심 기능(문서 편집 + Claude 에이전트 + 트래커)에 집중했습니다.
AI 수정 검토는 원본처럼 편집기 안에 줄 단위로 표시하지 않고, 문서 전체 diff 화면에서 한꺼번에 수락/되돌리기 합니다.
